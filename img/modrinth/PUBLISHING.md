# Modrinth assets

## Project icon

Upload [`icon.png`](icon.png) as the Modrinth project icon. It is a 512 × 512 PNG with transparent
corners, featuring an original pixel-art house and cyan teleport doorway on a grass-block base.
The editable vector source is [`icon.svg`](icon.svg).

## Gallery

Upload these PNGs to the project's Modrinth gallery in this order. Use **Save a home** as the
featured gallery image. Each image is cropped to 848 × 408 pixels without resizing the gameplay text.

| File | Gallery title | Caption |
| --- | --- | --- |
| `save-home.png` | Save a home | `/sethome desert` saves your location and facing direction. |
| `list-homes.png` | List your homes | `/homes` shows your saved locations. |
| `teleport-home.png` | Return home | `/home desert` teleports you to your saved location. |
| `delete-home.png` | Delete a home | `/delhome cave` removes a saved location. |

The root README uses repository-relative image links for GitHub. When copying its screenshot section
into a Modrinth description, replace those links with the hosted image URLs from your uploads.
